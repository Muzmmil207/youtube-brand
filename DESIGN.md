# Design system

The video design system lives in [`video-template/`](video-template/).

- Read [`video-template/DESIGN.md`](video-template/DESIGN.md) before authoring a scene.
- Run scenes from `video-template/`: `npm run audit && npm run lint && npm run check`.
- Visual reference: `brand/bento-grid-2.png`.

`video-template/` is self-contained and copyable: tokens, components, nine scene
templates, a 144 s showcase, and the validation scripts all travel with it.
